# ChatBI 数据式对话分析 Agent

用自然语言对话完成数据分析的 ChatBI Agent 项目。

## 简介

本项目旨在把「对话」变成数据查询与分析入口：用户用自然语言提问，Agent 负责理解意图、生成并执行查询、汇总结果并给出可读的结论。

## 状态

仓库初始化中，功能代码待补充。

## 环境准备

```bash
git clone https://github.com/kylin-official/ChatBI数据式对话分析Agent.git
cd ChatBI数据式对话分析Agent

# 建议使用虚拟环境
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```
